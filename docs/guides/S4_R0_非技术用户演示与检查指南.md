# S4-R0 名义动力学闭环演示指南

本轮演示的是“机器人的位置和姿态由力、力矩闭环控制产生”，不是逐帧把机器人放到目标位置。打开本地 GIF 时，重点看蓝色机体是否围绕参考位置稳定、初始偏差是否回到参考点，以及绿色机械臂是否运动而机体仍稳定。

## 看什么

- `hover_hold_real_isaac_temporal.gif`：重力下悬停。
- `initial_offset_recovery_real_isaac_temporal.gif`：x 方向 0.10 m 初始偏差恢复。
- `arm_motion_hold_real_isaac_temporal.gif`：机械臂连续运动时的基座稳定和反作用耦合。

曲线图中，position error 越低越好；attitude error 表示倾斜角；speed 表示漂移速度；joint error 表示活动关节跟踪误差。clearance 是离冻结场景包络的保守距离，不能把它理解成真实网格碰撞证明。

## 本轮边界

本轮采用 `BASE_DYNAMIC_ARM_REACTION_SURROGATE_V1`：浮动刚体是真实 PhysX 动力学体，闭环通过 body wrench 和连续关节目标驱动；机械臂的质量/惯量与反作用力矩是可追溯的等效代理。完整闭链 articulation dynamics、风、接触任务、ROS/ROS2、训练和 S5 均未开始。
