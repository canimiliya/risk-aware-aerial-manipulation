## Step 6：硬件、系统和工具链命令审计

创建：

```text
scripts/audit/collect_s0_hardware.ps1
```

脚本必须只收集必要字段，不得导出完整系统清单或个人隐私。至少执行以下等价查询。

### 6.1 操作系统、CPU、内存

```powershell
Get-CimInstance Win32_OperatingSystem |
  Select-Object Caption, Version, BuildNumber, OSArchitecture

Get-CimInstance Win32_Processor |
  Select-Object Name, NumberOfCores, NumberOfLogicalProcessors, MaxClockSpeed

Get-CimInstance Win32_ComputerSystem |
  Select-Object TotalPhysicalMemory
```

### 6.2 GPU、显存和驱动

```powershell
nvidia-smi --query-gpu=name,memory.total,driver_version,compute_cap --format=csv,noheader
nvidia-smi
```

保存原始 `nvidia-smi` 前检查其中是否含不必要的进程路径。仓库证据优先保留查询模式结果和头部摘要，不提交完整进程列表。

另检查：

```powershell
where.exe nvidia-smi
where.exe nvcc
nvcc --version
```

`nvcc` 不存在只能说明本地 CUDA Toolkit 未安装，不能直接判断 GPU 或 Isaac Lab 不可用。

### 6.3 磁盘

同时检查 C 盘和项目所在 D 盘：

```powershell
Get-CimInstance Win32_LogicalDisk -Filter "DriveType=3" |
  Select-Object DeviceID, FileSystem, Size, FreeSpace
```

必须报告真实剩余空间，不能只报告“1 TB 总容量”。

### 6.4 WSL 与虚拟化线索

```powershell
wsl --status
wsl --list --verbose
wsl --version
```

不得在本轮启用 WSL 或安装发行版。

### 6.5 Python、Conda、Git 与 GitHub CLI

# 九、状态判定

最终执行报告只能使用以下状态之一：

### `SUBMITTED_S0_INITIALIZATION`

全部核心目标完成，已推送 GitHub，等待高级总控审查。

### `SUBMITTED_S0_WITH_LIMITATIONS`

工作区和 GitHub 初始化完成，但存在明确硬件、驱动、磁盘、WSL、工具链或第三方许可证限制。限制必须逐项说明，不得掩盖。

### `BLOCKED_S0_WORKSPACE`

工作区嵌套、远程不一致、权限或原始文件问题导致无法安全初始化。

### `BLOCKED_S0_GIT_PUSH`

本地工作与证据完成，但认证或网络导致无法推送。必须保留本地 commit 和错误日志，不得声称已经提交 GitHub。

### `BLOCKED_S0_HARDWARE_STRATEGY`

硬件或操作系统存在明确硬阻断，且当前没有可信的本地或远程运行方案。

执行 Agent 不得使用 `PASS`；通过与否由高级总控审查决定。

# 十、失败与阻断处理

1. 命令失败必须记录命令、时间、退出码和关键错误；
2. 网络查询失败时可重试一次，仍失败则标记 `NOT_VERIFIED_DUE_TO_NETWORK`；
3. Git push 失败不得反复修改远程或使用强推；
4. 发现敏感信息时先从暂存区移除并记录，不得将密钥提交后再删除；
5. 发现路径或仓库污染时立即停止写操作；
6. 发现硬件低于要求时完成审计，不得自行购买、升级或切换平台；
7. 不得为了获得理想状态删除失败日志或编造成功输出。
